[generation effect](https://nesslabs.com/generation-effect-3) refers to the phenomenon where the brain remembers things it 'generated' better than things it reads passively. example - making your own flashcards, creating teaching material, doing a project from scratch.

it is ironic then that the benefits of the generation effect are being shattered by generative ai. consider projects and hackathons for example. these are a great format for learning. you are in a competetive environment where you're building something and learning about it along the way. that now, especially for coding can be done with a single prompt. 

consider coding. i'm doing a visualisation project. what i've realised is that asking llm for code skips through 2-3 layers of mistakes and learnings you'd have achieved if you tried it on your own. specially true for beginners. 

but then again one could argue that within 2-3 years, given the pace of ai development, no one would need to do all this stuff anyway. so i guess the process of learning will become a hobby. 

no one will need to learn anything in order to do something in the future, but there will be people who will be learning hobbyists. for brain health or/and for fun. fun times ahead.
